# 批注路由与作者手册

状态：已接受（2026-10-20）

## 背景

作者介入的成本不在改字，而在每次都要临场决定：改哪里、怎么告诉 AI、改完以后还有哪些东西要跟着动。改在正文里的东西，AI 下一章也不知道。

## 决定

- 作者介入只用一种格式：在草稿或正文里写批注，格式由 SOP 规定。只是改字的话直接改，不用批注。
- AI 处理批注时先判断病根在哪一层，改在那一层，再重做受影响的下游：

  | 病根 | 改哪里 | 跟着动 |
  | --- | --- | --- |
  | 措辞、单句 | 原地 | 无 |
  | 反复出现的写法毛病 | 作者手册 | 重写本章受影响的段落 |
  | 本章的情节、场景安排 | 章纲 | 本章重新起草 |
  | 单元节奏、后续情节 | 单元节奏表 | 受影响的章纲 |
  | 事实设定 | 百科 | 账本 |

  改动落在作者拍板的层（ADR 0003）时，AI 先写成提议，作者确认后才生效。
- 作者手册放在工作区根目录，跨书使用，记录作者的写法偏好和禁忌。每章定稿时，AI 对比草稿与定稿，把作者反复做的同类修改整理成手册条目候选，作者批量确认或拒绝。同类修改出现两次以上才提，一次性的取舍不当规律。
- 起草前，AI 必须读作者手册。

## 后果

作者手册是章枢里唯一会越用越值钱的资产，也可能被一时的偏好污染，所以只走确认制，作者随时可以删条目。这一点和 oh-story 的选择相反：它不从作者的修改里推断偏好；我们推断，但必须经作者确认才生效。
